# Telegram Mini App

এটি একটি টেলিগ্রাম মিনি অ্যাপ প্রজেক্ট যার ব্যাকএন্ড Node.js এবং Express দিয়ে তৈরি করা হয়েছে।

## সেটআপ নির্দেশিকা:
1. `package.json` ফাইল তৈরি করে ডিপেন্ডেন্সিগুলো যুক্ত করুন।
2. `index.js` ফাইলে আপনার টেলিগ্রাম বটের টোকেন সেট করুন।
3. প্রজেক্ট রান করতে টার্মিনালে `npm install` এবং তারপর `npm start` কমান্ড দিন।
